**大题库**：题库文件按"目录 + 每库一个文件"存放 —— `banks-v1.json` 只记题库元数据（题数、
题型分布、内容指纹），题目在 `banks/<bankId>/questions-v1.ndjson` 里一行一题。所以打开应用
不需要解析任何题目（十万题的库：重开 3ms / 7MB），练习某个库时才读它自己那份文件，写一个库也不会
碰其他库。NDJSON 是逐行导入的，一行写坏只损失那一行。旧版本的"题目内嵌"格式会在首次读取时
自动迁移，并在首页横幅告知。

但这套布局的代价也是量出来的，不靠感觉。已经拆掉的两条：

- **取一道题**：389ms → **1ms**（索引就绪后；第一次要先解析该库的索引，83ms）。
  每个库目录里多一张 `offsets-v1.tsv`（题号 → 行位置，十万题约 2.1MB），
  读题变成"读那一道题的那一行"。索引是派生数据，有结构/条数/内容三道锁，
  任何一道不过就重建 —— 这次也不会错，只是慢。
- **加一道题**：226ms → **26ms**（写 682 字节）。查重不再读整份文件，改成查表。

还没动的两条，就是 P11 剩下的验收缺口：

- **搜一个词 1.26s**（全表扫描）—— 要 ≤50ms 得有倒排索引或 FTS；
- **改 / 删一道题仍是整库重写**（49.9MB、471ms）—— 有偏移表之后可以做成"改一行 + 重排后面偏移"。

[docs/STATUS-P10.md](./docs/STATUS-P10.md) 第 20、21 节，更早的导入/重开数据在
[docs/STATUS-P3.md](./docs/STATUS-P3.md)。

**移除题库**：题库卡片底部「移除题库」（二次确认，就地确认，不弹模态框）。移除会删掉这个库的
题目文件与媒体字节，以及指向它的图谱关系；**历史、复核、笔记、收藏一条不动** —— 错题本里那些题
按「关联已失效」标注，笔记里那几句是自己写的字。挂在它上面的未完成练习会一起放弃
（已提交的记录仍在历史里）。移除不可撤销，退路是 `.qbk` 备份。

**题干与解析支持 Markdown + LaTeX**：`**粗体**`、`*斜体*`、`` `代码` ``、列表、引用，
行内公式 `$f = \frac{1}{2\pi\sqrt{LC}}$`，独立公式 `$$ ... $$`（分式 / 根式 / 上下标 / 求和积分 /
矩阵 / 常用希腊字母与运算符）。渲染完全离线（自写解析与排版，无 CDN、无 WebView），
不认识的命令按源码显示而不是静默吞掉。手工新建题目时编辑器下方有实时预览。

**键盘作答**：练习页在有物理键盘的设备上可以直接按键 —— `A/B/C…` 或 `1/2/3…` 选中对应选项，
`Enter` 提交；判完之后再按 `Enter` 就是下一题（最后一题去总结）。简答题的回车留给换行，
提交用 `Ctrl/Cmd + Enter`，因为逐字符判定的答案可能有多行。带 `Ctrl`/`Alt`/`Cmd` 的组合
一律不管，剪贴板与浏览器快捷键照常可用；重组题没有键位（它是点片段，没有可数的序号）。
手机上不显示这些提示 —— 写了只会让人到处找按键。

**深色模式**：首页右上角「◐ 跟随系统 / 浅色 / 深色」，点一下换下一个，选完立刻存
（`prefs-v1.json`，随 `.qbk` 备份一起搬），默认跟随系统。两套配色都是令牌（`PaletteScheme`）：
浅色是"暖纸 + 墨"，深色是"墨夜 + 纸字" —— 不是把浅色调暗，而是把纸墨关系倒过来。
主色因此拆成两个：`Accent` 当底（上面压白字）、`AccentInk` 当字（链接、图标、胶囊文字），
因为一个颜色不可能同时满足这两件事。对比度不靠眼睛调：`PaletteContrastTest` 按 WCAG
逐对算 48 条（正文 7:1、次级 4.5:1、提示级 2.5:1），`ThemeWiringTest` 真的渲染整页再读像素，
验证"点了按钮 → 屏幕真的换色"。

**笔记**：题库卡片进入「笔记」记资料来源与使用心得，练习页题干右上「✎ 写笔记」记思路与易错点，
也可以新建不关联题库的临时草稿。支持搜索、置顶、Markdown 与公式预览，全部保存在本机
（`notes-v1.json`），不参与判题、不影响统计。

**工具箱**：首页「∑ 工具」或练习页题干右上「∑ 工具」。计算器支持 `+ − × ÷ ^ ! %`、括号、
隐式乘法（`2π`、`3sin(30)`、`2(3+4)`）、三角函数与 ln/lg/log、sqrt/abs/round 等，角度制可切换；
报错会指出在第几个字符附近。单位换算按维度组织（长度/面积/体积/质量/时间/速度/温度/压强/能量/功率/角度/数据量），
温度按偏移公式换算而不是乘比例，市制与 BTU 这类非精确系数会在结果下方标注。做题时打开工具会记进历史
（问答反馈里显示"本题用过辅助工具"），但不影响判题。

**知识图谱**：首页「⇄ 图谱」或练习页题干右上「⇄ 关联」。可以跨题库把两道题连成
「相关 / 前置 / 依据 / 对比」，每条关系可以选择只做「导航」，或声明成「判题硬依赖」。
关系只存 `bankId + questionId` 引用，不复制题目正文；建关系时会留一份两端快照，题库暂时
不在本机时靠它认出"这是哪道题"，并明确标注「快照」——快照不参与判题。重新导入同一题库
（UUID、题号、内容版本都一致）会自动恢复；内容版本变了则标成「内容已变化」，需要你看过
当前内容后点「复核确认」。硬依赖缺失时，练习页的关联入口会变红，反馈面板写明
「本题有 N 条判题硬依赖缺失，相关依据已暂停」。图谱不会按标题相似的题库替你猜关系。

**扩展包（.qbext）**：作者可以把自己整理好的跨库关系与讲解注释打包发给你，首页「⊞ 扩展包」导入。
包里**只有** `relations/` 与 `annotations/` —— 题目、答案、历史一个字都不会被改。
按题库 UUID 绑定（标题只作显示）：题库还没装时包会显示「等待题库」，关系照样存下，
题库装上后自动生效，反过来先装库后装包也一样。同一个包的新版本可以升级，同版本重复安装会被
指出"已安装"，降级会被拒绝（软件不替你覆盖新版）。移除一个包只会删掉它带来的关系与注释，
你手工建的关系原样保留。制包工具：`python tools/qbank/qbext.py build <目录> -o <文件>`，
示例源码在 `tools/qbank/examples/qbext-authoring/`。

**多语言题库**：`.qbank` 里 `locales/<语言>/questions.ndjson` 有多少种语言，导入时就收多少种。
练习设置页会列出语言与覆盖度（如 `英语 · en 2/6`）；**没翻译的题默认不会被抽到**，
而不是拿中文题面配中文答案冒充英文练习。想练全也可以打开「缺译文时看原文」，
那些题的题干会挂一个「原文」徽章，判题用原文答案。作答历史按语言记录：
英文里答对的题不会让中文的「未练习」少一题，历史页也能按语言筛选。
语言标签只接受 `language[-Script][-REGION]`（`zh-Hans`、`en`、`pt-BR`），
`zh` 与 `zh-Hans` 不做模糊匹配，简繁同时存在时不替你猜。

**AI 讲解（可选，桌面端）**：首页「✦ AI 讲解」填接口地址、模型名与密钥 —— 支持任何 OpenAI 兼容接口
（云端 API、本地 Ollama / LM Studio 都行，本地地址允许 http），勾选「同意上传本题内容」后保存。
练习页作答后，题干右上出现「AI 讲解」：**只发这一道题**的题干、选项、正确答案和你的答案，
不带笔记、历史、其他题库。生成后状态是「结构已校验」而不是「正确」，本地只检查非空、长度与不可见字符；
你可以点「有用 / 没用」留下自己的判断，这条判断会存下来。
同一道题再点不会重复请求（缓存按题目、语言、内容版本、模型分开），失败也不会自动重试 ——
重试就等于再花一次钱。每日调用次数、token 与费用（按你填的单价估算）三道闸门都在发请求之前判断，
没配置、没同意、超预算时一次请求都不会发出去。

**批量生成**：AI 页里的「批量生成队列」可以把这个库里还没有讲解的题一次排好。
「排进队列」只建清单、一次请求都不发，同时把「已有讲解」「没有该语言题面」「超出 500 道上限」
三类排除掉并报数；看清楚之后再点「开始」。开始后一次只发一个请求，随时可以暂停（在请求边界生效，
不打断正在飞的请求）、继续、取消；到本次上限或每日预算用尽时自动暂停，剩余项保持待处理，
明天点继续就行。失败的那几道不会自动重试，也不会让整个任务停下。
任务存在本机，关掉应用再打开还在 —— 但**不做后台运行**，关掉就是停。

**题库更新（.qbpatch）**：作者改了题库之后，可以不发整包，而是发一份「从第 1 版到第 2 版改了什么」的补丁。
把补丁拖进窗口（或从「导入」页选择），会先进「题库更新」页 —— **在你点「应用更新」之前，一个字节都不会写**。
页面上先摆四件事：新增/修改/删除各几道、**哪几道题的答案变了**（以及你在那几道题上练过几次），
再逐条列出会改什么。补丁自带两个锚点：整库内容指纹（判定"这是不是我要改的那一版"）与每道题的指纹
（判定"你手里这条还是不是我要改的那条"），对不上一律拒绝，**没有"尽力应用"模式**。
应用后题库版本号 +1，首页题库卡出现「第 2 版」徽章；**练习历史一条都不会被改动** ——
答案变了只告诉你，要不要按新答案复核旧记录由你自己决定（见下一节）。同一个补丁再装一次会显示「不需要更新」
（`PATCH_NO_EFFECT` 在逻辑里是好消息，不是错误）；比本地旧的补丁不提供应用按钮。
应用记录写在 `bank-revisions-v1.json`（只有摘要，不含旧题目正文）。
制包命令：`python tools/qbank/qbpatch.py build <authoring目录> --base 旧包.qbank -o 补丁.qbpatch`，
校验：`python tools/qbank/qbpatch.py validate <补丁>`；示例源码在 `tools/qbank/examples/patch-authoring/`。

**历史复核**：作者改了正确答案之后，你过去那些"按当时的标准判对了"的记录会变成"按现在的标准是错的"。
软件不会替你重判 —— 首页工具栏出现「↻ 复核 N」，点进去逐条看到「当时判的 X」和「按现在重算 Y」，
配上当时的作答与现在的标准答案，由你决定：

- **按新答案：错误** —— 采用重算结果，正确率、错题本立刻跟着变；
- **维持：正确** —— 什么都不改，只是记下你看过了，以后不再问你。

两种决定都会写一条记录（`attempt-reviews-v1.ndjson`），**历史文件本身一个字节都不动**：
每条记录存的仍是当时提交的答案和当时的判定，复核结果只是挂在它上面的一层痕迹。
所以历史页上能看到"复核改判：当时判 正确，你按新答案改成了 错误"，而不是一条来路不明的判定。
题目再被改一次时，旧决定的前提就没了，那条记录会重新出现在待复核里。

**来源真实性**：题库可以声明"这些题是哪来的"，每道题也可以各自标一次。
练习页题干下面永远有一行出处，**四种状态在字面上就分开**：

| 作者写的 | 界面显示 |
|---|---|
| `origin: authored` | `作者原创`（参考了某本书时补一句「参考 甲教材 · 2020」） |
| `origin: adapted` + `sourceId` + `sourceLocator` | `改编自 甲教材 · 2020 · 第二章第三节` |
| `origin: imported` + `sourceId` | `引自 甲教材 · 2020` |
| `origin: ai-assisted` | 琥珀胶囊 `AI 参与生成` |
| **什么都没写** | **`来源未标注`** |

最后一行是这一块最要紧的设计：**"作者没说"绝不等同于"作者原创"**。软件没有那本书，判不了真伪，
所以它只做两件事 —— 原样转述作者的声明，以及把"没说"单独立成一态（而不是留空、更不是补一句原创）。

怎么写出处，在制包目录的 `manifest.json` 里加一段 `sources`，题目里引用它的 `sourceId`：

```json
"sources": [
  {
```

`kind` 可选 `book / paper / web / course / original / other`；`sourceId` 只能用小写字母、数字与 `_.-`，
长度 1~64。题目引用了 `sources` 里没有的 `sourceId` 会**直接拒绝导入**（`SOURCE_UNKNOWN`）——
引用一条不存在出处的题，比不标出处更可疑。两种"说了但没说清"只给警告：
声称 `改编 / 引用` 却没给 `sourceId`（`ORIGIN_WITHOUT_SOURCE`）、
给了 `sourceId` 却没写 `sourceLocator`（`SOURCE_LOCATOR_MISSING`）—— 位置缺失太常见，不该挡住一次导入。

**整包摘要 `contentDigest`**：打包工具会自动算一个 sha256（64 位十六进制）写进清单，
覆盖格式版本、题库 ID、内容版本、语言、标题、作者、许可和**每个文件的哈希**。
它只依赖逻辑内容，与 ZIP 时间戳、压缩级别无关 —— 同内容换工具重打，摘要相同。
对方装包时应用会重算一遍并比对：一致才在导入结果里写"内容摘要一致"，对不上直接拒绝
（`CONTENT_DIGEST_MISMATCH`，说明"你手上这份和作者发出来的不是同一份"）。
**注意它是防手滑，不是防篡改**：没有密钥、没有签名，改完内容重新打一次包摘要就自洽了。
能发现"作者改了包但忘了告诉你"，防不住"有人故意改了再发给你"。

出处和摘要都是**声明，不是证明**：应用只能核对"包里引用的出处确实在包里"，
核对不了"这本书第 42 页真有这道题"。这一点页面上也照实写着。

**本机备份与换机器（.qbk）**：首页「⇩ 备份」→「导出备份」，选个位置保存，得到一个 `.qbk` 文件。
它装的是**这台机器上你能看见的全部数据**：题库（含题面与图片）、作答历史、复核决定、笔记、
知识图谱、扩展包、AI 讲解缓存与生成队列。换机器时在新机器上「选择备份文件」，看到清单再确认恢复。

`.qbk` 和 `.qbank` 是**两套格式，不要混**：`.qbank` 是"一个题库的内容，给别人"，
`.qbk` 是"整台机器的全部数据，给自己"。它们只共用 ZIP 与 sha256，其余各管各的 ——
把 `.qbank` 拖进来是"导入"，把 `.qbk` 拖进来是"恢复"，应用按包里的清单文件名自动分辨。

备份里的数据是**按字节抄走的**，不解析、不重组。所以恢复后 `bankId`、题号、作答时间戳、
当初的复核决定全都原样不动 —— 历史不会因为换机器而"重新开始"。

恢复会**整体替换**本机数据，所以页面上先摆清楚再让你点：

| 预览里写的 | 意思 |
|---|---|
| 备份时间 / 来源设备 | 这份备份是什么时候、从哪台机器来的 |
| 格式版本 / 数据布局版本 | 各有一个版本号，比本应用支持的更高就**直接拒绝**，没有"尽力恢复" |
| 几个文件 / 原始数据多大 | 文件数与解压后的体积 |
| 里面有：N 个题库 / M 道题 / K 条历史 / 笔记 / 图片 | 这个包里到底有什么 |
| 本机现在：N 个题库 / M 条历史 | 并排摆着，用来判断"会不会盖掉更重要的东西" |

点「恢复」之后如果本机原有数据，它不会被删掉，而是被改名成 `*.pre-restore-<时间>` 留在旁边，
恢复成功的横幅里直接给出路径 —— 恢复错了还能自己捞回来。下次恢复时才清理更早的那一份。

**恢复中途断电 / 被杀掉会怎样**：恢复全程记一份日志（`<数据目录名>.restore-journal.json`，
刻意写在数据目录**外面**，因为最危险的瞬间数据目录恰好不存在）。下次启动时先看日志再读数据：

| 上次停在哪 | 启动时怎么办 |
|---|---|
| 新数据还没写完 | 半成品清掉，本机数据一个字节没动 |
| 新数据写完、换上去那一下断了 | 直接接上新数据（写完时已逐文件核对过字节数） |
| 旧数据已移走、新数据不完整 | 把旧数据放回原位，等于恢复之前的样子 |
| 换好了、只差删日志 | 认下来，旧数据仍然留在旁边 |
| 数据目录和旧数据都不在了 | 不假装正常：说清路径，让你自己去找 |

备份页会留一张卡片写清"现在生效的是哪一份数据、被换下来的旧数据在哪"，首页只在启动时说一次、
点过「知道了」就不再提。这条只能说"修好"，不承诺零丢失 —— 断电正好落在改名与写日志之间时，
靠的是磁盘现场本身可分辨（数据目录在或不在），而不是日志。

**加密备份（口令）**：导出面板上有「加密：开 / 关」胶囊，**默认关**。打开之后要输两遍口令
（至少 10 个字符），并自己勾一句「我知道：忘记口令就打不开」—— 不勾不给导出，导出按钮上直接写原因。

打开加密后包里的东西是这样分的：

| 位置 | 里面有什么 | 谁能看 |
|---|---|---|
| `backup-manifest.json`（明文） | 格式版本、导出时间、来源设备、应用版本、几个统计数字、KDF 与密码参数 | 拿到文件的人 |
| `payload.enc`（密文） | 索引 + 全部文件字节；**每个文件的路径、大小、sha256 都在这里** | 只有知道口令的人 |

信封必须明文，否则连"这份备份要不要口令"都问不出来。代价就是那几个统计数字被看见 —— 页面照实写。
文件名和逐文件摘要一定要进密文：明文摘要等于给"猜文件内容"提供了验证器，猜到就能确认，加密就白做了。

口令走 **PBKDF2-HMAC-SHA256（600000 轮，16 字节随机盐）→ 32 字节密钥 → AES-256-GCM（12 字节随机 nonce）**。
`kdf` / `iterations` / `salt` / `cipher` / `nonce` 全部写在信封里，所以将来换 Argon2id 只是多一个 `kdf` 取值，
不用换格式版本。读别人的文件时轮数 `< 50000` 或 `> 4000000` 都直接拒绝：前者防"把轮数改小加速爆破"，
后者防一次解密卡几分钟。

解不开的时候只给**一个**错误码（`BACKUP_DECRYPT_FAILED`），文案明说"口令错和文件被改过，
这两件事在密码学上分不开"。不硬说"口令错误"，否则拿到坏文件的人会一直重试口令。

- **加密默认关闭**：默认加密会让"备份完了却打不开"成为最常见的事故。要开就得自己勾后果那一句。
- **口令不可找回**：没有提示问题、没有密钥文件、没有后门。忘记口令 = 那份备份永久打不开。
- **加密备份上限 64 MiB**：纯 Kotlin 的 GHASH 约 20 MB/s，更大的数据只能用不加密的备份（解压总量上限 500 MiB）。
- **不加密时仍然全裸**：关掉开关，同一个文件谁拿到谁能看 —— 琥珀块就是为这句话存在的。
- **只有桌面端能做**：Web / iOS 的数据在内存里，关掉就没了，没有可备份的东西；Android 还没有
  "保存到用户选的位置"的通道。这两处只写原因，不摆点了没反应的按钮。
- **恢复不能合并**：只有"整体替换"。合并出一种既不是备份、也不是本机的第三种状态，比不合并更糟。
- **中断恢复只能修好，不能零丢失**：自愈只在启动时跑一次；断电正好落在改名与写日志之间时，靠现场分辨。
- **没有"撤销上一次恢复"按钮**：退路是把 `*.pre-restore-*` 手工改回原名，界面只给路径。
- **备份文件不压缩**：体积约等于原始数据大小。换来的是导出恢复都不依赖压缩库。
- **摘要不是签名**：它能发现"文件被截断或被改过"，防不住"有人改了再给你"。

**引用自检（这份数据里有没有东西指着空处）**：备份页中间有一块「引用自检」。它不评价内容好坏，
只看**谁指着谁、指的那个东西还在不在**：

| 查什么 | 怎么算接不上 |
|---|---|
| 图谱关系 | 两端分别落在哪个题库、哪道题 |
| 笔记 | 题库笔记看库在不在；题目笔记还要看那道题在不在；草稿按定义没有归属，不算 |
| 扩展包 | 绑定的题库、每条注释指定的题；包带来的关系已经在图谱里，不重复计 |
| 历史 | 只看**库**在不在 —— 补丁删题之后仍留着"当初确实做过"的记录，那不是悬空 |
| 题目里的图 | 题目写的 `assetId` 在数据目录里到底有没有那张文件（路径规则与写入方共用同一个函数） |

三件事说清楚：

- **只报告，不拦截。** 指空的引用是既有状态，不是打包失败。为它挡住导出，等于因为"有十条关系没接上"
  就不让用户拿到唯一的退路。
- **按目标合并，不按记录罗列。** 十条关系指着同一个没装的题库，只算**一个**目标 ——
  用户要处理的是一个题库，不是十件事。
- **接不上不等于坏。** 卸载题库、更新题库时删掉题，都会让引用暂时指空。装上 bankId 相同的题库会自动接上；
  题目级的引用不会被悄悄抹掉（那是用户自己建过的东西）。

跑的三个时机：**进备份页、导出成功、恢复成功**。恢复后跑就是"数据换完再解析一遍引用"。
检查的是**真正打包 / 写进去的那份文件清单**，不是"此刻磁盘上恰好有什么" —— 两者之间隔着一次打包。

- **只查"在不在"，不查"对不对"**：关系建错了对象、把 A 题的前置写成 B 题，自检看不出来。
- **不检查内容本身**：题干写错、答案标错、笔记里错别字，都不是它的事。
- **媒体只核对文件在不在**：文件被换成另一张图、或者被截断，它发现不了（逐文件摘要属于备份容器的职责）。
- **Web / iOS 的图片一项会跳过**：那两处的数据在内存里，给不出文件清单，界面明说"没有核对"而不是假装查过。
- **结论不写进备份文件**：那是**导出那一刻**的判断，而用户是恢复之后才看它，中间可能过了半年、装过别的题库。

**界面与动效**：统一的设计令牌、组件与动效规则见 [docs/UI-DESIGN.md](./docs/UI-DESIGN.md)。
不开窗口核对界面：`KT_SHOTS=1 ./gradlew :shared:jvmTest --tests "*ScreenshotTest*"`，

**制作 .qbank 题库**：把你的学习资料交给 AI 时，连同 `tools/qbank-authoring-skill/` 整个目录一起提供
（入口是它的 `SKILL.md`），AI 会按标准产出真包并用随附工具校验。手工打包 / 校验命令：
`python tools/qbank/build_qbank.py <authoring目录>` 与

### Running the apps

Use the run configurations provided by the run widget in your IDE's toolbar. You can also use these commands and
options:

- Android app: `./gradlew :androidApp:assembleDebug` (AGP 9 需要 JDK：`-Porg.gradle.java.installations.paths=<JDK 路径>`)
- Desktop app:
    - Standard run: `./gradlew :desktopApp:run`
    - Hot reload: 尚未配置（未应用 `org.jetbrains.compose.hot-reload` 插件，`:desktopApp:hotRun` 任务不存在）
- Web app:
    - Wasm target (faster, modern browsers): `./gradlew :webApp:wasmJsBrowserDevelopmentRun`
    - JS target (slower, supports older browsers): `./gradlew :webApp:jsBrowserDevelopmentRun`
- iOS app: open the [/iosApp](./iosApp) directory in Xcode and run it from there.
